## `01 / TRANSMISSION`

I'm **Adarsh Muchatte**, a B.Tech Information Technology student at **VIT Vellore** who likes building websites you can explore rather than just scroll. Most of my public work is browser-based 3D and interactive storytelling, built with JavaScript, Three.js and WebGL shaders.

Full-stack foundations, a strong frontend eye, and a habit of shipping immersive, interactive experiences that run straight in the browser.

- 🚀 **Building:** immersive, interactive web projects
- 🌌 **Exploring:** React and Node.js, extending the frontend into full-stack
- 🧠 **Practising:** data structures and algorithms in C++ and Java
- 🤝 **Open to:** SDE, full-stack and web development internships
